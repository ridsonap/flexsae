# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`flexsae` is an R package (GPL-3, in development) for **area-level** small area estimation with
non-linear covariate effects: `pspline_sae()` (semiparametric Fay-Herriot with penalized splines,
REML via `mgcv`), `merf_sae()` (Fay-Herriot with a random forest fixed part, `ranger`) and the
experimental `boost_sae()` (XGBoost fixed part) and `scfh_sae()` (spatially clustered Fay-Herriot), with
parametric bootstrap MSE, covariate selection, benchmarking and `ggplot2` plots. Unit-level methods
are planned later. The design, references and phases are in `PLAN.md` (Indonesian). It follows the
conventions of the sister package `fastsae` (github.com/ridsonap/fastsae).

## Commands

```sh
Rscript -e 'devtools::document()'      # regenerate man/ and NAMESPACE (roxygen, markdown on)
Rscript -e 'devtools::test()'          # test suite
Rscript -e 'devtools::check()'         # R CMD check
R CMD INSTALL . --preclean             # install before running benchmarks/ or rendering vignettes
```

Scripts in `benchmarks/` use the **installed** package, not `load_all()`.

```sh
Rscript benchmarks/simulation/run.R point 300 10   # simulation study (hours; results/ is git-ignored)
Rscript benchmarks/simulation/run.R mse 200 10
Rscript benchmarks/update_benchmark_docs.R         # summaries -> inst/extdata/simulation.rds
```

`vignettes/simulation.Rmd` only reads `inst/extdata/simulation.rds`; rerun the two steps above after
changing a model.

## Conventions

- Naming: model functions `*_sae` (`pspline_sae`, `merf_sae`); utilities `*_flexsae`
  (`benchmark_flexsae`, `select_flexsae`, ...) so they do not mask fastsae's `benchmark_sae`,
  `step_sae`, `compare_sae`, `map_sae`.
- Internal column names start with `.flexsae_`; user data may not use that prefix.
- One result class: `c("flexsae_<model>", "flexsae")` with a `df_est` table of fixed columns
  (`domain, direct, vardir, est, synthetic, random_effect, gamma, mse, rse, ci_lower, ci_upper, sampled`); columns that do not
  apply are `NA`, never dropped. Shared S3 methods work on that shape.
- Validate inputs at the top of each function with `cli::cli_abort()`; non-convergence gives
  `convergence = FALSE` plus a warning.
- `NAMESPACE` is generated by roxygen (unlike fastsae, where it is written by hand).
- Every bug fix comes with a test that fails before the fix.

## References and deviations

- Cite only entries in `technical-report/references.bib`; every one was verified against
  Crossref, the publisher or the official PDF. Unverified items are in
  `technical-report/TODO_REFERENCES.md` and must not be cited. Verify any new reference
  (Crossref/DOI) before adding it; do not write DOIs from memory.
- Deliberate deviations from the papers or reference packages go in
  `technical-report/DISCREPANCIES.md`, roxygen `@details` and `NEWS.md`.
- `mgcv::gam(y ~ ... + s(domain, bs = "re"), weights = 1/vardir, scale = 1, method = "REML")`
  reproduces `sae::eblupFH` REML (check S1 in `DISCREPANCIES.md`); the random effect variance is
  `scale / sp`. Keep that agreement under test. `.fit_fh_lm()` must agree with `sae::eblupFH` too.
- `merf_sae(algorithm = "fhrf")` follows Bukhari et al. (2026) as published (one pass, OOB);
  `algorithm = "merf"` is our own unpublished adaptation (MERF-3) and must stay labelled experimental. `emdi::fh` agrees only to ~1e-4 because of its
  optimizer tolerance (check S2); do not tighten that test.

## Code map

- `R/area_data.R`: `.prepare_area_data()` validates the area-level input and builds the fitting data
  (internal columns `.flexsae_y`, `.flexsae_area`, `.flexsae_w`).
- `R/fh_gam.R`: `.fit_fh_gam()` / `.predict_fh_gam()`, the Fay-Herriot fit through mgcv shared by the models.
- `R/mse_bootstrap.R`: `.pboot_mse()`, naive parametric bootstrap; the model passes a `refit()` closure.
- `R/fh_lm.R`: `.fit_fh_lm()`, linear Fay-Herriot with one variance component by profile REML/ML
  (grid + `optimize()`), used by `merf_sae()` because mgcv is O(D^3) per fit (check S5).
- `R/merf_sae.R`: `merf_sae()`, `.merf_fit()` (one fit with a `learner`, shared with `boost_sae()`, reused per bootstrap replicate),
  `.fhrf_combine()` (EBLUP step, eqs. 10/14 of Bukhari et al. 2026), `.fit_rf()` (ranger, OOB).
- `R/boost_sae.R`: `boost_sae()` (experimental, own area-level adaptation; xgboost in Suggests),
  `.fit_boost()` (cross-fitted predictions for sampled areas: an area never sees its own target),
  `.boost_nrounds()` (xgb.cv), `.boost_matrix()`. It reuses `.merf_fit(learner = )`; keep `merf_sae()`
  identical to `tests/testthat/fixtures/merf_reference.rds`.
- `R/scfh_sae.R`: `scfh_sae()` (experimental, Maranzano et al. 2026 preprint), `.scfh_fit()` (one fit,
  reused per bootstrap replicate: k-means start, AREML per cluster, ICM label sweeps), `.label_unsampled()`
  (own extension, SCFH-1), `.align_labels()`, `.adjusted_rand()`. Keep `K = 1` equal to `sae::eblupFH`
  and AREML equal to `emdi::fh(method = "amrl")` (check S10).
- `R/benchmark.R`: `benchmark_flexsae()` (S3: `flexsae`, numeric default), `.benchmark_core()`,
  `.bm_rule()` (rules follow fastsae's `.benchmark_worker`). The MSE re-benchmarks the stored model
  bootstrap replicates (`boot_errors`, `boot_theta`, `boot_y`); keep those fields in every model.
- `R/self_benchmark.R`: `.self_benchmark_cols()` (z_d = w_d * vardir_d by group, Wang-Fuller-Qu
  eq. 23) and `.check_self_benchmark()`; used by both models through `bench_weight`/`bench_group`.
- `R/select.R` (`select_flexsae()`, `.refit_flexsae()` refits with the object's settings,
  `.pspline_ic()`), `R/importance.R`, `R/partial.R` (`.fixed_part_fun()`), `R/autoplot.R`
  (re-exports `ggplot2::autoplot`).
- `R/pspline_sae.R`, `R/methods.R` (print/summary/coef/fitted/residuals), `R/utils.R`.
